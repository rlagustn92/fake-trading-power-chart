# FAKE TRADING POWER CHART

과거 차트를 **리플레이**하면서 가상 돈으로 **롱·숏 매매를 연습**하는 프로그램. 차트 위 익절·손절선을 마우스로 끌어 바꾼다.
원본 `POWER CHART AND BACKTEST`(차트 + 적립식 백테스트)를 2026-10-30에 복제해서 만들었다. 원본의 차트·지표·그리기·백테스트는 그대로 들어 있다.
**진짜 주문은 없다.** 모든 체결은 이 PC 안의 계산이고, 거래소 주문 API는 코드도 주소도 없다.

## 받기·새 버전으로 바꾸기
- 이 저장소의 **Releases**에서 `FAKE-TRADING-POWER-CHART.exe`를 받는다. 설치 없이 EXE 하나로 켜진다. WebView2 필요 — Win11·최신 Win10 기본
- 새 버전 (0.15.0부터): 앱이 켤 때·12시간마다 알아서 확인해서 "🆕 새 버전이 있어요" → **보기 → 받고 다시 켜기**. ⚙ 설정 맨 위 "🆕 새 버전 확인"으로 언제든. 받은 파일은 GitHub의 확인값(SHA-256)과 같을 때만 쓴다
- 손으로 바꿀 때: **앱을 끄고 EXE만 새것으로 바꿔 켜면 끝.** 차트 데이터·관심종목·그린 것·거래 기록·키는 EXE가 아니라 `%APPDATA%\fake-trading-power-chart`와 Windows 자격 증명 관리자에 있어서 그대로 남는다
- 서명이 없는 EXE라 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행"

## 💰 모의매매 쓰기
1. 툴바의 **💰 모의매매**를 누르면 오른쪽에 창이 열린다.
2. 처음 한 번: 창의 **과거 1분봉 → "30일 받기"** (Binance 종목, 약 30초. "상장일부터"는 1~2분).
3. **🎲 아무 때나 시작** (받아 둔 기간 중 아무 때나) 또는 **📍 차트에서 시작점 고르기** → 그 뒤 봉은 가려진다.
4. `Space` 재생 · `→` 한 칸(1분). 속도는 위쪽 보라색 줄에서 (1·2·5·10·30분/초).
5. **레버리지**(1~20배 버튼, 또는 옆 칸에 원하는 숫자를 소수점 두 자리까지 — 예: 3.75)를 고르고, 수량은 **증거금으로**(내 돈을 직접) 또는 **손절 기준**(손절에 닿으면 계좌의 0.5·1·2·3%만 잃게 저절로) 중에서 정한다. 포지션 크기 = 증거금 × 배율.
   - **미리 깔기**: "롱 대기선 / 숏 대기선"을 누르면 진입선(점선)이 생긴다. 끌어서 원하는 가격에 두면 가격이 닿을 때 들어간다 (현재가 아래 롱 = 지정가, 위 롱 = 돌파. 숏은 반대).
6. **매수 (롱)** `B` / **매도 (숏)** `S` → 평단선 + 익절선·손절선이 **꺼진 채로(회색 점선)** 생긴다. **선이나 이름표를 잡고 위아래로 끌어** 자리를 잡고, **선을 오른쪽 클릭**하면 켜진다(익절 초록·손절 주황). 꺼진 선은 닿아도 정리되지 않는다. 포지션 칸의 켜짐/꺼짐 버튼이나 숫자 입력도 된다 (⚙에서 "처음에 켜 두기"로 바꿀 수 있음). 레버리지를 쓰면 **청산가선(자홍색)**도 생긴다 (늘 켜짐).
7. **분할 매수**: 들고 있는 쪽 버튼(추가 매수 / 추가 매도)을 또 누른다 → 평단이 다시 계산된다.
8. **원하는 양만 정리**: 25%·50%·75% 버튼, 또는 수량을 쳐서 [정리]. 전부: **전부 종료** `X`.
9. 가격이 선에 닿으면 자동으로 정리되고 손익(수수료·미끄러짐 뺀 돈)이 계좌에 들어간다. 청산가에 닿으면 "강제 청산".
10. 리플레이 중에도 봉(1분·5분·15분·1시간…)을 바꿀 수 있다 — 같은 시각부터 이어 간다. 5분봉도 1분씩 자란다. **⏭ 한 칸(→) = 지금 보는 봉 하나** (1시간봉이면 1시간), **Shift+→ = 1분** (0.14.1)
11. **거래 기록**: 💰 창 아래에 숫자 칸 4개 + 최근 5개. **📒 전체 일지 열기** → 누적 손익 곡선, 모든 거래 표, 종목·롱/숏·연습 판별로 걸러 보기. 카드나 줄을 누르면 그 시점 차트로 가서 들어간 곳·나온 곳을 보여 준다 (복기). 줄의 ✎ = 메모, **📄 CSV 저장** = `문서\FAKE TRADING POWER CHART\`. 들고 있는 동안 포지션 칸 아래 메모 칸에 적어도 기록에 남는다.

12. **📡 지금 실시간으로** (💰 창의 시작 버튼 아래): 지금 보고 있는 차트의 실시간 가격으로 연습한다. 버튼·선·단축키는 리플레이와 같다. 위쪽 ■ 끝내기 (또는 종목을 바꾸면) → 들고 있던 것은 그 가격으로 정리. 바이낸스 종목은 24시간, 주식은 장중에만 가격이 움직인다. 들고 있다가 앱을 끄면 다음에 켤 때 마지막으로 본 가격으로 정리해 기록한다.
13. **국내 주식 분봉을 더 옛날까지**: 토스 키가 있으면 💰 창 "차트 봉"에서 **📥 2년치 받기 → 2년 더** (토스에 약 4년치) — 1분봉을 받아 5분·1시간봉도 만들어 두므로 4시간·1시간·15분·5분봉이 그만큼 뒤로 보이고, 1분봉 리플레이도 된다 (2년에 3~5분, 멈춰도 이어서). 토스 키가 없으면 야후가 주는 만큼(1분 30일·5분 60일·1시간 2년)
14. **차트 봉을 한 번에 2년치** (0.9.0): Binance 종목은 💰 창 "차트 봉 (5분·15분·30분·1시간·4시간)"의 **📥 2년치 받기** — 2~3분, 다시 누르면 2년 더(4년·6년…), 상장한 지 2년이 안 되면 상장일까지. 차트를 왼쪽 끝으로 당겨 받아도 되지만 한 번에 약 15일씩이라, 5분·15분봉을 당기면 이 버튼이 든 알림이 한 번 뜬다. 미국 주식(알파카 키)은 5분봉을 원래 2016년부터 저절로 받는다
15. **겹쳐보기 "가격 그대로"** (0.10.0): 보기 ▾ → 비교 → ＋ 비교 종목 넣기(예: SOXL 차트에 SOXX) → **가격 그대로 (눈금 두 개)**. 오른쪽 = SOXL 가격, 왼쪽 = SOXX 가격. 마우스를 올리면 그날 실제 가격이 두 눈금에 뜬다 (흰 = SOXL 그날 종가, 주황 = SOXX 그날 가격). 두 선은 오른쪽 끝에서 만나게 맞춰서, 회색 가로선 양 끝을 읽으면 "지금부터 SOXX가 여기 가면 SOXL은 대략 여기". 범례에 "보이는 기간 SOXX 1% ≈ SOXL 3.1%"와 그 시각의 두 가격. 짧은 기간(1~3개월)일수록 잘 맞고, 길게 보면 옛날 쪽은 3배 상품의 녹아내림만큼 벌어진다. "% 비교"는 전처럼 누가 더 올랐나
16. **봉 색 한국식·미국식** (0.13.0): ⚙ 설정 → 차트 → 봉 색. 한국식 = 오르면 빨강·내리면 파랑, 미국식 = 오르면 초록·내리면 빨강. 매수/매도 버튼·롱/숏 선·거래 기록 손익 색도 같이. 지표·그리기 색은 16가지 + 🎨 직접 고르기
17. **분할 화면 + 모의매매** (0.13.0): 리플레이 중에 칸 수를 늘려도 새 칸이 같은 시각으로 붙고, 줄여도 매매하는 칸이 남으면 이어 간다. 포지션·대기선이 있는데 판이 끝나는 일(매매 칸 종목 바꾸기, 🎲 새로 시작, ✕ 끝내기 등)을 하면 먼저 "⚠ 모의매매 중이에요"라고 묻는다. 차트 봉 2년치 받기는 보기 ▾ 메뉴에도 있다

체결 규칙: 그 종목 **1분봉**으로 판단 · 한 1분봉에서 익절·손절이 둘 다 닿으면 손절 먼저(청산가가 더 가까우면 청산) · 익절(지정가)은 한 틱 넘게 지나가야 · 시가가 선을 건너뛰면 시가로 · 시장가는 미끄러짐 + 시장가 수수료 · 청산은 격리 증거금, 유지증거금 = 최대 레버리지 증거금의 절반 (Hyperliquid 방식). 수수료·처음 선 위치·최대 레버리지·시작 자금은 💰 창 맨 아래 ⚙.

## 쓰기 (원본에서 이어받은 것)
- 프로그램은 **`release\FAKE TRADING POWER CHART.exe` 하나** (바탕화면 바로가기 `FAKE TRADING POWER CHART`, 주황 F 아이콘). 원본 POWER CHART와 동시에 켜도 된다. WebView2 필요 — Win11·최신 Win10 기본
- 처음 켜면 관심종목 일봉을 받아 `%APPDATA%\fake-trading-power-chart\market.db`에 쌓는다 (원본과 다른 폴더). 그다음부터는 빠진 부분만 이어 받는다 (🔄 버튼으로도)
- 기본 관심종목은 Binance 주식 무기한선물(NVDA·TSLA·QQQ·SPY·SOXL…, 24시간). 종목 찾기에서 `bn:` 뒤에 Binance 이름을 써도 된다 (예: `bn:HOODUSDT`)
- Binance 종목(BTC 포함)은 처음에 봉마다 최근 4,500개만 받는다 (5분봉 약 15일). **차트를 왼쪽 끝까지 밀면 그 앞을 더 받아 온다** (한 번에 약 15일씩, 상장일까지. 키 필요 없음). 옛날 구간에서 리플레이를 시작하면 그때 1분봉도 저절로 받는다 (1~2초)
- 미국 주식 분봉: ⚙ 설정 → 데이터 → 알파카 키 입력 (Windows 자격 증명 관리자, 이 앱 이름 `fake-trading-power-chart`로 따로 저장 — 원본 앱 키와 섞이지 않음)
- 국내 실시간: Market Board·원본 앱과 **같은** 토스 키·토큰을 같이 쓴다 (이름을 바꾸면 서로 토큰을 끊어서 일부러 같게 둠)
- 어디서 받는지: 차트 머리줄 오른쪽 표시에 마우스를 올리면 현재가·일봉·분봉 출처가 나온다
- CSV 가져오기: 일봉 CSV 파일을 창에 끌어다 놓기
- 차트 이미지 복사 (0.18.0): 차트 위 오른쪽 클릭 → `📋 차트 이미지 복사` → 카톡 등에 Ctrl+V. 분할 화면이면 `📋 화면 전체 복사`(한 장으로) · `📋 이 칸만 복사`
- 그리기: 도구를 한 번 고르면 계속 그린다. 우클릭·Esc = 취소 → 한 번 더 = 그만. 그린 것을 누르면 뜨는 설정 막대는 `—`로 접고 `✏️`로 펼친다 (0.19.0, 접은 채로 기억)
- 추세선 쉽게 긋기 (0.20.0): Magnet을 켜면 고점·저점 근처를 대충 찍어도 진짜 꼭지점에 붙는다 (동그라미로 미리 보임, Shift = 자석 없이). 선을 누르고 `∥ 평행선` → 두 점 사이 가장 낮은 저점에 같은 기울기로 붙는다
- 다른 PC로 옮기기: ⚙ 설정 → 데이터 → `💾 백업 만들기` → `FAKE-TRADING-날짜` 폴더를 새 PC의 EXE와 같은 폴더에 두고 처음 켜기. 원본 앱 백업의 market.db도 `📂 파일에서 가져오기`로 가져올 수 있다 (형식이 같다)
