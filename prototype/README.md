# 주문선 시험판 (프로토타입)

만든 날 **2026-10-30**. 기획서 §12 진행 순서의 **1단계 "주문선 드래그 프로토타입 (단일 HTML)"**.
목적: 차트 위 익절·손절선을 마우스로 끌어 바꾸는 **조작감**을 본 개발 전에 확인한다. 진짜 주문은 없다.

![시험판 화면](screenshot.jpg)

## 여는 법
- `orderlines.html`을 **더블클릭**하면 브라우저에서 열린다 (같은 폴더의 `lightweight-charts…js`, `sample_bars.js`를 읽는다).
- 또는 개발 서버: `python -m http.server 5190 --bind 127.0.0.1 --directory prototype` → http://localhost:5190/orderlines.html
  (원본 앱 개발 포트 5180과 겹치지 않게 5190. `.claude/launch.json`의 `prototype`)
- 시험 데이터 새로 받기: `python prototype/fetch_sample.py NVDAUSDT 3` (Binance 1분봉 3일치, 키 없음, 요청 3번)

## 들어 있는 것
- NVDA 1분봉(Binance 주식 무기한선물) **리플레이**: 재생·멈춤, 한 봉씩, 속도 1·2·5·10배, 다른 시점에서 다시
- **매수(롱)·매도(숏)** 큰 버튼 → 평단선 + **익절선(초록)·손절선(주황)** 이 생긴다 (처음엔 +0.5% / −0.25%, 손익비 2)
- **선이나 이름표를 잡고 위아래로 끌기**, 또는 오른쪽 칸에 숫자 직접 입력
- 이름표: 가격, 그 가격에 나가면 손익(수수료 뺀 돈), %, 손익비
- 자동 체결: 한 봉 안에서 둘 다 닿으면 **손절 먼저** · 익절은 **한 틱 넘게 지나가야** · 시가가 선을 건너뛰면 **시가로**
- 수수료 가정: 시장가 0.09%, 익절(지정가) 0.03% (trade.xyz 기본값. 확정 아님)
- 단축키: Space 재생·멈춤, → 한 봉, B 매수, S 매도, X 종료

## 만들면서 알게 된 것 → 본 개발에 그대로 넣을 것
1. **원본 그리기 도구(`web/drawings/layer.js`) 방식으로 충분하다.** 누르기를 차트보다 먼저 받아 막고(capture), 끄는 동안 차트 이동을 잠근다. 기획서 §10 위험 "프리미티브로 조작감이 충분한가"는 1차로 **충분**. 마지막 판단은 사용자가 직접 써 보고.
2. **가격선은 차트 자동 눈금에 안 들어간다** → 익절선이 화면 밖으로 나갔다. `autoscaleInfoProvider`로 익절·손절을 범위에 넣었다.
3. **끄는 동안엔 눈금을 멈춰야** 선이 마우스에서 미끄러지지 않는다. 놓은 직후 바로 다시 맞추면 차트 전체가 휙 바뀌어서, **다음 봉이 올 때** 다시 맞춘다.
4. 선이 가까우면 **이름표가 겹친다** → 위아래로 32px씩 비켜 놓는다 (선은 제자리).
5. Claude 미리보기 창은 파일을 `data:` 주소로 열어서 옆 파일을 못 읽는다 → 시험은 5190 서버로 했다.

## 아직 안 한 것

- 터치(태블릿) 끌기
- 1분봉을 재생하며 5·15분봉 합성, 봉 안의 움직임 보여 주기 (지금은 1분봉이 통째로 나타난다)
- 진입 전에 선 먼저 놓기, 지정가 진입선, 분할 청산, 손절 기준 수량 자동 계산 (기획서상 MVP 뒤)
